# Maintenance and decisions

| Role | Contact | Scope |
| --- | --- | --- |
| Project maintainer | [Xzare / @yousefbadran6888-ux](https://github.com/yousefbadran6888-ux) | Source review, issue triage, release decisions and security-report coordination |

Public questions belong in repository issues. Security and conduct reports go to **hello@xzare.com**. There is no dedicated support SLA.

The maintainer makes final merge and release decisions. Significant changes should explain their user need, compatibility impact and verification in an issue or pull request. A release should identify the exact commit and its checks, distinguish source releases from signed installers, and document unresolved limitations.

Additional maintainers can be listed after sustained contributions and explicit agreement on responsibilities. No additional team members, user counts or adoption metrics are claimed by this document.
