# Xzare Pharmacy 0.1.0

المنتج العاشر: تشغيل الصيدلية بوحدات صحيحة وبمخزون تتبع تشغيلة وصلاحية، لا بيانات أعمال مُسبقة.

## بدء التشغيل
شغّل المثبت ثم البرنامج من الاختصار، أو شغّل Xzare Pharmacy.exe داخل مجلد win-unpacked كاملًا. أنشئ اسم الصيدلية ومسؤولًا وكلمة مرور خاصة من12حرفًا على الأقل. أضف الأدوية والباركود والوحدة والسعر، ثم المورد الفعلي، واستلم التشغيلات بمرجع المورد وتاريخ صلاحية وتكلفة إجمالية.

## العمليات المتاحة
- كاونتر بحث أو قارئ باركود USB بوضع keyboard ثم Enter؛ أصفار البداية محفوظة. CODE128 للأكواد الداخلية وEAN13/EAN8/UPCA للكود التجاري مع تحقق رقم المراجعة. ملصق قابل للطباعة.
- كل كمية عدد صحيح من وحدة التسجيل (علبة أو شريط مُعرّف لديك). لا تحويل تلقائي بين الوحدات؛ الوحدة ثابتة بعد الاستلام.
- الصرف يتوزع تلقائيًا على الأقرب انتهاءً؛ تاريخ الصلاحية ثابت للتشغيلة. يوم الانتهاء نفسه محظور، ويُمنع المنتهي أو المعزول أو المسحوب أو الدواء المتوقف.
- فواتير ذات أسعار وأسماء ووحدات مجمدة، خصم وضريبة يحددها المستخدم، دفع كامل أو جزئي نقدي/بطاقة/تحويل، والتحصيل اللاحق بمرجع. الطرق تسجل التحصيل ولا تحرك أموالًا لدى بنك أو بوابة دفع.
- مرتجع جزئي على التشغيلات المصروفة فعلًا، مع السبب والمرجع. المخزون المرتجع معزول دائمًا ولا يعود للبيع حتى بتغيير حالة التشغيلة؛ يسجل هالكه منفصلًا. تخفض مديونية الفاتورة ويُرد الزائد من المدفوع مع حفظ السجل.
- عزل/سحب/إعادة إتاحة التشغيلة بسبب موثق، تسجيل الهالك مع فحص الرصيد لمنع الكتابة على عرض قديم، وتطابق الأرصدة مع دفتر الحركة.
- روابط أدوية بديلة يسجلها المستخدم يدويًا؛ لا اقتراحات أو استنتاج تكافؤ أو وصف دوائي.
- تقارير بالفترة المحلية تشمل التحصيل والاسترداد وحركات التشغيلات، وتصديرCSV عربي يحمي من حقن الصيغ. قائمة الفواتير آخر1000 مستند، والتقرير يشمل الفترة كاملة.
- صلاحيات مسؤول/مدير/موظف كاونتر، سجل تدقيق ونسخ يومية وآلية استعادة تُنهي الجلسات وتحفظ ترخيص الجهاز.

## حدود الإصدار
الاستلام يسجل الكمية والتكلفة ومرجع المورد، ولا ينشئ حساب مديونية وسداد المورد. لا إدارة وصفات أو أدوية رقابية أو مطالبات تأمين أو استنتاجات طبية. لا تفترض جاهزية قانونية لأي سوق من واجهة المخزون. قاعدة البيانات والنسخ الاحتياطية غير مشفرة؛ احفظها في مكان محمي.
