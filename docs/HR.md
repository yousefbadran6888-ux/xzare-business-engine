# Xzare HR 0.1.0

المنتج الحادي عشر: إدارة ملفات الموظفين والورديات والحضور والإجازات والتقييم ومسيرات الرواتب. تبدأ النسخة دون موظفين أو مسيرات تجريبية.

## التشغيل
شغّل Xzare-HR-0.1.0-Setup.exe للتثبيت، أو win-unpacked\Xzare HR.exe مع إبقاء كل الملفات بجواره. أنشئ اسم شركتك وحساب المسؤول بكلمة مرور خاصة لا تقل عن 12 حرفًا.

## سير العمل
1. أضف الموظفين بكود مميز وتاريخ التعيين. بيانات التواصل والملاحظات اختيارية.
2. أنشئ قوالب ورديات، ثم عيّن وردية أو يوم راحة لكل موظف ولكل يوم في جدول الأسبوع. الوردية التي تنتهي قبل وقت بدايتها تمتد لليوم التالي. لا تُستنتج أيام الراحة تلقائيًا. تعديل القالب لا يغير أيامًا سبق تسجيلها.
3. سجّل الحضور المكتمل يدويًا أو الغياب. اختر تاريخ اليوم التالي للخروج في الوردية الليلية. يمنع النظام تداخل فترات العمل ووقت الخروج المستقبلي. التصحيح يحتاج نسخة السجل الحالية وسببًا محفوظًا. لا يوجد تكامل جهاز بصمة مفعّل.
4. امنح رصيد إجازات مدفوعة وفق سياسة شركتك. الطلب يشمل أيامًا مجدولة بالكامل ويحسب أيام العمل فقط؛ داخل سنة واحدة وبحد أقصى93يومًا. الاعتماد يستهلك الرصيد؛ إلغاء الاعتماد يعيده. لا توجد قواعد أرصدة قانونية افتراضية.
5. التقييم يدوي من1إلى5 لجودة العمل والالتزام والتعاون، مع أهداف وملاحظات. لا يؤثر تلقائيًا في الراتب أو قرارات التوظيف.
6. مسؤول الرواتب يسجل الأساس الشهري ثم يختار موظفي المسير ومبالغ البدلات والإضافي والاستقطاعات والضريبة والتأمين. الحساب بالسنت/القرش الصحيح، لا كسور عائمة. الأساس لا يُجزأ تلقائيًا عند التعيين/انتهاء العمل؛ يجب إدخال تسويات معتمدة. الحضور مرجع محفوظ داخل المسير ولا يتحول تلقائيًا إلى خصم أو إضافي مالي.
7. بعد الإرسال تثبت الأسماء والمبالغ ونسخ الحضور. مستخدم مختلف بصلاحية مدير أو مسؤول رواتب أو مسؤول نظام يعتمدها. يمكن تسجيل صرف جزئي حتى الصافي فقط، بمرجع وطريقة. التسجيل يوثق صرفًا نُفذ بالفعل ولا ينفذ تحويلًا مصرفيًا. لا يمكن إلغاء مسير به صرف. يمكن إلغاء مسير غير مصروف وإعداد بديل للشهر مع حفظ التاريخ.

## الصلاحيات والخصوصية
مسؤول النظام يدير المستخدمين والإعدادات والنسخ. المدير يرى شؤون الموظفين والرواتب. شؤون الموظفين يدير الملفات والحضور والإجازات والتقييم دون رؤية أساس الأجر أو المسيرات. مسؤول الرواتب يرى بيانات العمل الضرورية والأجور دون ملاحظات الموظفين الشخصية أو التقييمات أو أسباب الإجازات. المستخدمون حسابات تشغيل مستقلة، وليست بوابة خدمة ذاتية للموظفين.

## التقارير والنسخ
تقرير الحضور لفترة حتى93يومًا، CSV آمن من صيغ الخلايا، طباعة تقرير ومسير. جدول الأسبوع يعرض الفترات الماضية والمقبلة؛ قائمة الإجازات لها نطاق تاريخ تختاره للطلبات السابقة واللاحقة، ورصيد الإجازات يُعرض حسب السنة المختارة. مسيرات أحدث1000 وتقييمات أحدث1000 وسجل تدقيق أحدث300؛ السجلات الأقدم تظل في قاعدة البيانات. نسخة .xzbak خاصة بمنتجHR؛ الاستعادة تحتاج كلمة مرور المسؤول وتنهي الجلسات وتحفظ نسخة قبل الاستبدال. بيانات العمل والنسخ الاحتياطية غير مشفرة؛ احفظها على جهاز وموقع موثوقين. حماية مفتاح الجهاز بتخزينWindows الآمن لا تشفر ملفات الموظفين.

## التفعيل والأمان
مسار الترخيص يستخدم تفعيل الإنترنت مع ربط المنتج والجهاز ومهلة محدودة دون اتصال. تجديد بعد إعادة تشغيل النظام وفق إعداد النسخة. المفتاح الخاص للجهاز لا يظهر في الواجهة ولا يدخل ملفات الإصدار؛ مفاتيح إصدار تراخيص العملاء ليست ضمن البرنامج. عزلElectron وsandbox وحمايةASAR وفحص الصلاحيات والطلبات وسجل العمليات مفعّلة. لا توجد حماية من الاختراق أو نسخ البرنامج بنسبة100%.
