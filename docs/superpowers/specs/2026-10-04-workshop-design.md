# Xzare Workshop 0.1.0 — design
Product #6: standalone Arabic vehicle workshop Windows app. Same hardened identity/inventory/backup/device license core, distinct schema/application ID/product identity/data directory. One company/EGP. No fabricated commercial rows. User authorized portfolio and successive products; proceed inline.

## Workflow and invariant
Customer vehicle (owner name, contact, unique normalized plate, optional unique VIN, make/model/year, mileage). Technician registry. Received work order freezes vehicle/customer snapshot, entry mileage, complaint, promised date and source warehouse. Only one open order per vehicle; odometer cannot move backwards. Estimate revisions are immutable, with diagnosis, service descriptions/qty/prices and parts from barcode catalog. Integer milli quantities and cents, BigInt half-up line totals, discount <= subtotal and tax bps <=10000. Approve latest revision records customer's approval reference and active technician. Order financial facts freeze at approval; subsequent catalog/vehicle changes cannot alter accepted terms.
Start checks active technician and parts, consumes nonexpired FEFO lots atomically into the order, immutable allocation cost. Serial parts issue only full units; all-or-nothing shortage failure. Actual labor cost and repair/inspection notes on ready; mileage-out cannot decrease. Cost = parts actual issue cost + actual labor cost. Immutable payments only on ready order, cannot overpay; delivered requires full payment and handover reference. Received/estimated/approved may cancel with reason; started cannot cancel/pretend stock returned. Terminal orders immutable. Every write actor/payload-bound idempotent and audited. Dates validated, input lengths/arrays/cents bounded. Manager/admin write, cashier view-only.

## UI and scope
Workshop overview, vehicles/history, technicians, receipt/estimate/approval/repair/ready/payment/handover order flow, printable order invoice/receipt, CSV jobs/payment report, barcode parts/catalog/labels, warehouses/real stock movements/counts/lots, users/audit/settings/license/backup. All UI fresh genuine empty states; own workshop navigation, own icon. Shared inventory panels reused as neutral stock components.
No fabricated accounting ledger: collected revenue, receivables, actual job cost and margin report. No electronic tax submission, deposits/refunds, recursive repair stock undo, bookings/capacity or remote server included in0.1. No fake status shortcuts. Report query full history with date/status filters; capped current list visibly counted.
